# apps/web

Next.js web application for BuildQuote Data Studio.

Handles:
- Manufacturer login
- Source document upload
- Extraction status display
- Visual verification UI (side-by-side PDF vs system card)
- Approval and rejection workflow

## Structure

```
app/          Next.js app router pages and layouts
components/   Shared UI components
lib/          Utilities, API clients, Supabase client
```

## Status

Scaffold only. Not yet implemented.
